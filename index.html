Méthode

Quatre étapes, du cadrage à la mise en service, chacune illustrée par une pièce tirée de mon travail.

  1. 01Écrire les décisions

    Depuis août 2026, chaque chantier commence par une note de cadrage, et les arbitrages sont consignés et datés dans un registre. La personne qui reprendra l’outil saura pourquoi il fonctionne ainsi.

  2. 02Encadrer les agents de code

    Je développe avec des agents de code : Claude Code (dans VS Code) et Antigravity. L’agent écrit le code ; je fixe les règles, je tranche et je vérifie le résultat à l’écran et sur le terrain. Une tâche n’est terminée que lorsque l’agent montre la sortie réelle des tests.

  3. 03Vérifier chaque test

    Pour savoir si un test protège quelque chose, je casse volontairement le comportement qu’il couvre et je vérifie qu’il échoue. Sur une vingtaine d’assertions de l’ERP, l’exercice a montré que près d’un tiers étaient fausses ou vérifiaient autre chose que prévu.

  4. 04Préparer la mise en service

    Je vérifie les sauvegardes en les restaurant sur une base neuve. J’écris aussi la procédure de mise en service, un guide pour chaque rôle et le document de passation.
